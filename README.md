# CostKeeper

CostKeeper is a modern Android expense tracking application built with Jetpack Compose, Room database, and MVVM architecture.

## Features
- Track daily income and expenses
- Dynamic categories and budget management
- Interactive analytics with custom pie charts and legend breakdowns
- Export reports to PDF
- Currency selection and dark/light theme support
- Fully offline local persistence with Room (KSP)

## Tech Stack
- **Language**: Kotlin 1.9.24
- **UI Framework**: Jetpack Compose (Material 3)
- **Database**: Room 2.6.1 (with KSP)
- **Target SDK**: 35 (Android 15)
- **Compile SDK**: 35
- **Minimum SDK**: 24 (Android 7.0)
- **Gradle**: 8.9 / AGP 8.7.3
